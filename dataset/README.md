# Real or Fake? dataset

A small starter dataset for a "Real or Fake?" game that teaches everyday people to spot AI-generated images,
AI-written texts and scam messages. Every item has a **difficulty (1–5)**, **clues** and a plain-language
**explanation**, so the app can start easy and teach as it goes.

| Category        | Real                               | Fake                                         | Count   |
| --------------- | ---------------------------------- | -------------------------------------------- | ------- |
| `ai-image`      | photos from Wikimedia Commons (everyday + featured), incl. adults in public scenes | AI images from CommunityForensics (37 generators, old GANs to Midjourney 6.1 / FLUX / Imagen 3) | 110 + 88 |
| `ai-vs-human`   | real SMS (UCI SMS Spam Collection) | AI-written by Claude                         | 30 + 30 |
| `scam-vs-legit` | legit notifications (by Claude)    | real old spam (UCI) + modern scams by Claude | 30 + 30 |

**318 items in total, and every category has items at every difficulty from 1 to 5.** Run `npm run data:offline` to print the table.

To add content, see **[HOW_TO_ADD.md](HOW_TO_ADD.md)**. To browse it, run `npm run preview` and open
http://localhost:3000/dataset/preview.html

## Files

| Path                    | What                                                                       |
| ----------------------- | -------------------------------------------------------------------------- |
| `items.csv`             | **source of truth**, edit this (Excel / GitHub)                            |
| `items.json`            | generated by `npm run data`, this is what the app loads                    |
| `images/`               | every image as `images/<id>.jpg` (max 512px). One folder and one file type, so the path never gives the answer away |
| `inbox/`                | drop new images here, `npm run data` files them away                       |
| `loader.js`             | zero-dependency JS helper for the app                                      |
| `preview.html`          | tiny page to browse pairs                                                  |

## Using it in the app

```js
import { loadDataset, getPair, getRound } from "./dataset/loader.js";

const items = await loadDataset(); // fetches dataset/items.json

// One pair: two images, target difficulty 2, one real + one fake
const pair = getPair(items, { modality: "image", difficulty: 2, mode: "one-fake" });
// pair.left / pair.right -> { id, is_real, src (images) or content (texts), clues, explanation, difficulty, source, ... }

// A whole round: 10 text pairs going from easy (1) to hard (5), never repeating an item
const round = getRound(items, { modality: "text", category: "scam-vs-legit", count: 10, start: 1, end: 5 });
```

`mode` can be `one-fake`, `both-real`, `both-fake` or `random` (one-fake is twice as likely). Pairs always share
modality and category, and prefer the same `subject` (bird with bird, bank with bank). `getPair` returns `null` if
nothing fits.

**Difficulty from real players (optional):** if the app stores `item.stats = { shown, correct }`, `difficultyOf(item)`
switches to the measured difficulty once an item has been shown 20 times.

## Item format (`items.json`)

```json
{
  "id": "img-0025",
  "modality": "image",
  "is_real": false,
  "category": "ai-image",
  "subject": "landscape",
  "content": "images/img-0025.jpg",
  "difficulty": 5,
  "difficulty_source": "claude",
  "clues": ["very convincing; buildings on the shore melt into the water line"],
  "explanation": "Sunsets are easy for AI. The only clue is the shoreline: the buildings don't have clear shapes.",
  "source": { "dataset": "CommunityForensics-Small", "license": "CC BY-NC-SA 4.0", "author": null,
              "generator": "EnD-Diffusers/Porcelain-Dusk-Mix-V1", "original_id": "EnD-Diffusers/Porcelain-Dusk-Mix-V1/00000351.png" },
  "added_by": "fetch-images"
}
```

`difficulty_source` is `team` (a person rated it), `claude` (Claude rated it) or `stats` (measured from players).

## Scripts

| Command                                         | What it does                                                                 |
| ----------------------------------------------- | ---------------------------------------------------------------------------- |
| `npm run data`                                  | build `items.json` from `items.csv` (Claude fills gaps if `.env` has a key)  |
| `npm run data:offline`                          | same, without calling Claude                                                 |
| `npm run generate -- --kind scam --count 10`    | Claude writes more messages (`ai-written`, `scam`, `legit`)                  |
| `npm run fetch:texts`                           | re-download the curated UCI messages (`-- --random` for a random sample)     |
| `npm run fetch:images -- --source eval --count 20` | download 20 more AI images (`--source wikimedia` for real photos)        |
| `npm run check`                                 | lint + format check + tests (also runs on every PR)                          |

Prompts used by Claude are in [`/prompts`](../prompts).

## How the content was checked

- Every image was reviewed by eye. Removed: anything showing children, close-up portraits, copyrighted characters,
  likenesses of real public figures, documents/text-heavy images and blank or junk images (16 in total so far).
- **People:** at the team's request the game includes people. AI people come from generator prompts. Real people come only
  from freely licensed Wikimedia photos of public scenes (markets, sport, music, work), skipping files flagged with
  personality rights. No names are stored. This is a deliberate exception to "no real personal data": remove any photo
  if someone asks.
- Texts: hand-reviewed UCI line numbers only (no private names, no adult content). Claude-written messages use made-up
  brands and fake links (e.g. `parcel-track-help.info`). No real phone numbers or links were added.
- The starter ratings (difficulty, clues, explanation) were written by Claude (Claude Code) after looking at each item.
  Test them with real players and adjust.
